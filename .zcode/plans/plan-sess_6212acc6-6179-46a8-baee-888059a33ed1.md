# 结果页优化计划

## 改动文件
- `lib/features/results/results_tab.dart` — 主要改动
- `lib/features/results/result_state.dart` — 添加 updateRow 方法

## 1. 字体放大
| 位置 | 当前 | 目标 |
|------|------|------|
| 统计卡标签 | 11px | 12px |
| 统计卡数值 | 18px | 22px |
| 表头 | 默认 | 13px bold |
| 节点列 | 14px mono | 14px mono（保持） |
| 延迟列 | 13px mono | 14px mono |
| 国家列 | 13px mono | 14px mono |
| 来源列 | 默认 mono | 14px mono |
| 分布芯片 | 默认 12px | 13px |

## 2. 排版优化
- 统计卡宽度 180→200，padding 增大
- 表头加底部边框分隔线，背景色加深
- 行高 56→60，给内容更多呼吸空间
- 国家分布区改为更紧凑的 Wrap + 带颜色 indicator 的小卡片
- 空状态区的双层边框简化为单层虚线感

## 3. 添加行编辑功能
- `_DataRowWidget` 在 editMode 下点击行 → 弹出编辑对话框（而非仅复制）
- 编辑对话框：可修改 ip:port#CC source 的各部分
- `ResultNotifier` 添加 `updateRow(int index, String rawLine)` 方法
- 编辑按钮（铅笔图标）显示在每行末尾（editMode 时）
