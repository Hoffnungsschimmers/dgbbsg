# 2026-10-02 开发交接

本轮范围：落实用户确认的可靠性、进度与取消、质量保护、恢复、自动任务、WebDAV 安全备份与状态、日志导出与轮换、缓存有效期、模板导出说明和 Windows 分发改进。保持原有 Flutter / Riverpod 架构，无新增依赖，无国家分类功能。

## 设计决策

- 每轮固定配置，修改配置作用于下一轮。公共单步动作不能插入正在运行的流水线。
- 自动更新三种模式，默认仍仅获取订阅，避免升级后自动执行额外推送。任务运行、同步和手动推送/恢复互斥。
- 默认推送门槛：至少 1 节点、50% 独立 IP 实测、数量不低于基线 50%。GeoIP 估计不算 POP 实测；门槛可配置。缩减结果被拦截后，重复执行仍保留旧基线；成功推送更新基线。
- 本地结果与 JSON 旁文件用内容 SHA-256 关联。每个文件先写临时文件、flush，再替换，异常时恢复上一版；进程中断后读文件会恢复 .previous。两文件之间中断时，哈希不符的旧证据不展示也不用于推送。
- 快照备份 TXT 和元信息，标记原始文件，恢复只接受当前文件的快照；恢复前备份当前文件。最多保留最近 20 份（目录共用）。
- 网络取消关闭当前 HttpClient、取消 Dio 和重试等待。已经提交到 GitHub 的请求无法保证远端撤销；取消摘要明确提示检查远端。
- WebDAV 默认排除密钥、订阅来源和 UUID；恢复保留本机相关字段，旧含密钥备份兼容。绝对路径同步有显式本地映射。
- 日志脱敏后进入内存、落盘和导出；按天保存，7 天裁剪，1 MB 后保留一个轮换文件。日志落盘失败不影响任务。
- GeoIP 缓存 7 天到期，旧无时间戳项不再使用，防止无限续期。
- CSV/TXT 为地址数据，客户端导出只是模板；协议认证信息没有被重新加入结果模型。
