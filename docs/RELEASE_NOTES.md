# 1.1.0+2 — 2026-10-02

- 运行阶段、处理数量、运行摘要和可取消的网络请求；取消会中断重试等待。
- 每轮配置固定，自动任务支持获取 / 获取并检测 / 全流程；并发任务互斥。
- 手动与自动推送共用质量门槛，区分 POP 实测和 GeoIP 估计；数量骤减保护基线保留到成功推送。
- 结果行显示证据来源；搜索、排序和编辑保留，分类芯片及分组删除。
- 结果页支持整段原始内容编辑（逐行校验，任一行非法即整批拒绝）、拖拽调序、撤销/重做（30 步）与未保存守卫；改过地址的行清空其落地证据，需重测才计入实测占比。
- 结果文件安全替换、内容与旁文件哈希校验、快照含证据，支持本地恢复。
- GeoIP 缓存有效期 7 天；旧无时间戳缓存自动重新查询。
- WebDAV 默认备份普通配置，恢复保留本机密钥与来源地址；同步互斥与状态反馈，自定义输出路径支持。
- 日志内存、落盘及导出前脱敏；按天滚动并裁剪历史日志。
- 客户端格式导出明确标为配置模板，导出前说明占位参数。
- 配置损坏保留原始备份并使用默认配置启动；配置保存串行化并提示失败。
- GitHub 读取使用指定分支 SHA，冲突重试收窄，直连模式的 TLS 选项修复。
- Windows 打包脚本、版本号、校验文件和 CI SDK 固定。
